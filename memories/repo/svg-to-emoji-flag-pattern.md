# SVG → Unicode Emoji Pattern

Извлечён из `d37de8c`.

## Проблема

- SVG-флаги занимали ~200KB
- Требовали загрузки через fetch/CSP
- CSP блокировал загрузку
- Некоторые SVG были повреждены

## Решение

Unicode Regional Indicator Symbols (флаги emoji):
- 0 дополнительной загрузки
- Без CSP проблем
- Автоматически актуальны
- Единый размер

## Правило

Если есть выбор между иконкой/изображением и Unicode:
1. Unicode всегда предпочтительнее
2. Emoji если нужен цвет/графика
3. SVG только когда ничего другое не подходит
4. CSS-стили если можно (border, background-color)

## Итог

- 200KB → 0KB (удаление всех SVG-флагов)
- Zero дополнительного кода
- CSP не затрагивается
