# Nginx Version Compatibility Pattern

Извлечён из 3 коммитов (`73f157c`, `2a75e1e`, `ad58d6c`).

## Проблема

- `http2` директива изменилась между nginx версиями (синтаксис)
- `gzip_proxied` `must-revalidate` не поддерживается на старой версии
- `__APP_DIR__` плейсхолдер восстановлен после того как был сломан

## Что сработало

Каждое изменение nginx конфига сопровождалось:
1. Тестом на target версии nginx
2. Коммитом с конкретным фиксом (не "починил всё")

## Когда применять

Перед изменением nginx конфига:
1. Узнать версию nginx на сервере (`nginx -v`)
2. Проверить директиву в документации этой версии
3. Не предполагать, что последний синтаксис работает везде

## Итог

Лучше минимальные изменения с конкретными коммитами, чем "массовый рефакторинг" nginx.
